PC Build Store - Output Screenshots
===================================

1. Dashboard - Main screen with hero banner, stats, and featured parts
2. Build Configurator - 6-slot PC builder with category tabs and product grid
3. Build Upgrades - Upgrade existing builds with compatibility checks
4. Billing - Purchase flow with receipt view, print, and save options
5. Reports - Revenue charts and performance analytics
6. AI Chat - Streaming chat bot with KoboldCPP integration
7. Add Part - Modal dialog for adding components via UI
8. Settings - Chat configuration dialog

Note: Run the application to capture live screenshots. The application
requires XAMPP MySQL running with pc_build_store database imported.
